## Frontmatter reference

| Field         | Type     | Required | Notes                                                 |
| ------------- | -------- | -------- | ----------------------------------------------------- |
| `title`       | string   | yes      |                                                       |
| `description` | string   | yes      | Shows in RSS, OG tags, and article cards              |
| `publishedAt` | date     | yes      | `YYYY-MM-DD` — sorts newest first                     |
| `updatedAt`   | date     | no       |                                                       |
| `tags`        | string[] | no       | Used for tag pages and related posts                  |
| `category`    | string   | no       | Displayed on article cards                            |
| `image`       | string   | no       | Path in /public for the social card image             |
| `featured`    | boolean  | no       | Featured posts show first (default: false)            |
| `draft`       | boolean  | no       | Hidden in production, visible in dev (default: false) |
